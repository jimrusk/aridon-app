# Content Integrity & Freshness lane

The Analyze Any Business workflow now includes a Content Integrity & Freshness score.

The lane is designed to catch public-site issues that strong authority and conversion signals can otherwise hide, including:

- cross-industry copy mismatches on program or challenge pages
- stale current-program language
- application-open claims after a displayed deadline
- duplicated long page descriptions
- mixed current and legacy branding in the scanned set

The lane is intentionally conservative. It only penalizes issues found in the pages Aridon actually scanned, and the result note explains that external indexing and canonical verification are separate technical checks.

Crawl coverage was expanded from three to six high-signal pages, with extra priority for challenges, initiatives, programs, membership, impact, events, and applications.
