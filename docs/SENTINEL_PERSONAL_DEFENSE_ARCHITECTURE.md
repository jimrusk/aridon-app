# Sentinel Personal Defense - Unified Customer Architecture

Customer
  -> Sentinel account
     -> Android Agent
     -> Windows/macOS Agent
     -> Identity & Account Monitor
     -> Financial Institution Connectors
     -> Money Guard Risk Engine
     -> Cross-Device Correlation
     -> Evidence Vault
     -> Customer Verification / Hold Request where institution supports it
     -> Incident & Recovery Package

Target consumer price: $49.99/month.

A Sentinel risk score never represents guaranteed fraud. Transaction holds/pauses require the financial institution/payment provider to expose and authorize that capability. Otherwise Sentinel alerts the customer and initiates supported institution-specific containment workflows.
