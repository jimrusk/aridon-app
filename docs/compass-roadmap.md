# Aridon Compass roadmap

- Alternative Housing Compass screen
- Four housing/community models
- Quick-fit capital, management and goal signals
- Evidence-first verification language
- Workspace navigation entry

## Next implementation layers
1. Persist Compass profiles per tenant/user.
2. Add general Business Compass intake.
3. Add Acquisition Compass with SDE, debt service, owner-income, seller-financing, staged-payment and earn-out preferences.
4. Connect executive voice/phone interviews to the same structured Compass schema.
5. Detect/confirm language and maintain caller language through the session.
6. Read back names, addresses, financial numbers and consequential facts before saving.
7. Add opportunity scoring only from verified deal/property data.
8. Require human approval for external sends, payments, contracts, applications and commitments.
