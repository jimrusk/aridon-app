# Aridon Compass release notes

Adds an Alternative Housing Compass to private customer workspaces. The initial module compares manufactured home parks, RV parks, combination MHP/RV communities, and tiny-home/park-model communities. It captures basic investor fit signals and directs users toward property-specific verification instead of presenting promotional claims as facts.

The workspace home now links to Compass. Future persistence and telephone intake will share the same structured profile model.
