# Aridon Index Engine

This branch adds the website indexing layer to Analyze Any Business.

Initial scope:
- Catalog scanned pages into an Aridon internal site index.
- Score search readiness and AI discovery readiness.
- Flag missing titles, descriptions, headings, and internal navigation.
- Surface owner-authorized submission setup for sitemap, Search Console, and IndexNow.
- Never claim guaranteed search-engine indexing.
