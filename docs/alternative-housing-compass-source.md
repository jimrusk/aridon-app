# Alternative Housing Compass source concept

Added from an owner-provided reference image on August 30, 2026.

The Aridon implementation uses the underlying investment categories as a research and diligence framework rather than reproducing the supplied infographic.

Categories incorporated:
- Manufactured home parks
- RV parks
- Manufactured home + RV combination communities
- Tiny-home / park-model communities

Aridon deliberately reframes promotional claims as hypotheses to verify. Property-level recommendations require evidence such as actual NOI, collections, occupancy, zoning, utilities, capex, debt terms, seller financing, insurance and downside scenarios.
