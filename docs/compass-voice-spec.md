# Voice-driven Compass intake

The same Compass should be usable without a computer.

Conversation flow:
1. Executive identifies the caller's preferred language and confirms it when uncertain.
2. Executive asks one plain-language question at a time.
3. Answers map into the same structured Compass fields used by the web UI.
4. Names, addresses, dollar amounts, percentages, dates, measurements and other high-impact facts are read back for confirmation.
5. Executive summarizes the resulting profile and explains what information remains unverified.
6. Structured records are saved only after the appropriate confirmation.
7. External sends, contracts, payments, applications and commitments remain approval-gated.

The system should retain original-language wording where useful and may maintain normalized internal fields for analysis without silently changing the caller's meaning.
