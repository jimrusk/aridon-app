# Aridon Sentinel Public Safety

Public-safety security surface for police, sheriff, fire, EMS, 911/dispatch, emergency management, and municipal critical systems.

## Core model
- Continuity-first containment
- Protected-asset classification for CAD/dispatch/radio/911/RMS systems
- Human approval for disruptive actions
- Two-person approval for mission-critical assets
- Break-glass emergency override with reason capture
- Append-only evidence/audit model
- Local continuity mode for cloud/internet outages
- Integrations-first response through existing EDR, identity, firewall, SIEM, backup, and ticketing systems

## Production-readiness gates
This product surface is not itself a compliance certification. Before a public-safety production deployment, Sentinel requires signed endpoint components, validated tenant isolation, hardened identity/RBAC, tested integrations, penetration testing, backup/disaster-recovery validation, agency-specific runbooks, and applicable CJIS/HIPAA/critical-infrastructure control mapping.
